🎃 Plataforma web desarrollada con Laravel para crear, administrar y explorar rutas de Halloween. Incluye mapas interactivos, geolocalización, gestión de destinos, participación de negocios, panel administrativo, Super Admin y diseño responsive con modo día/noche.

# 🎃 Rutas de los Dulces

**Rutas de los Dulces** es una plataforma web interactiva desarrollada con Laravel que permite descubrir, organizar y administrar rutas de Halloween, conectando familias, participantes y negocios mediante mapas y geolocalización.

### Características principales

- 🗺️ Mapas interactivos con Leaflet y OpenStreetMap.
- 📍 Geolocalización y visualización de destinos.
- 🎃 Creación y administración de rutas de Halloween.
- 🏪 Participación y registro de negocios.
- 🔐 Autenticación, roles y permisos.
- 📊 Dashboard administrativo y panel Super Admin.
- 🌙 Modo día/noche con diseño Liquid Glass.
- 📱 Interfaz responsive para computadoras y dispositivos móviles.

### Tecnologías

Laravel · PHP · MySQL · JavaScript · Blade · Tailwind CSS · Leaflet · OpenStreetMap

**Objetivo:** Facilitar la organización y exploración de rutas de dulces, ofreciendo una experiencia divertida, accesible y segura para la comunidad.
